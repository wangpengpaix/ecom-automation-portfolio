> **唯一对外入口**：<https://wangpengpaix.github.io/ecom-automation-portfolio/>
>
> 所有项目都在这一站里展示——已完结的项目**不做删除**，与在研项目**并列展示**；新项目在同一入口下增量接入。

## 项目

**电商运营自动化工作台**（2026-08 – 2026-09，已结项）
覆盖多平台店铺管理、售后工单归因、客服会话采集与 AI 分析的运营自动化工作台。约 2.4 万行后端与采集源码、150+ REST 接口、43 个业务模块、7 个能力域。已于 2026-09-23 结项归档，能力域与规模口径以结项时点封存。

**自媒体账号孵化器**（2026-09 – 至今，进行中）
把多平台发布收进一个后台：账号接进来 → 内容准备好 → 一键或定时发到多平台 → 看发布结果。以「官方 API / Web 接口直连 / 浏览器自动化」三通道应对各平台开放程度差异，公众号真发链路已端到端跑通（含 48001 自动降级）。

## 更新机制

- 工作日志与「近期更新」由**每日自动归档任务**维护：采集当天各项目的会话记录、产出文件与提交，提炼为条目后写入本仓库。
- 条目按**项目维度**区分：`ecom`（电商）/ `sm`（自媒体），在总览页与日志页以徽标标注。
- 同一天可承载多个项目的条目；重跑为**跳过已存在条目**（幂等），不会产生重复。

## 新增一个项目

1. 在 `projects/` 下新增该项目的详情页（可复用现有页面的版式）。
2. 在总览 `index.html` 的「项目一览」区新增一张项目卡。
3. 在工作日志页与总览页的 CSS 中新增该项目的徽标类。
4. 在生成流水线的 `PROJECTS` 注册表中登记该项目的标识与详情页路径。
